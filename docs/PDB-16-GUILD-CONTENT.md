# PDB-16 길드 컨텐츠 기획

> 작성: 2026-07-25 · 상태: **기획 초안(미구현)** · 구현 착수 전 승인 필요
> 선행 문서: `PDB-11-COMMAND-FOUNDATION`(멱등·revision), `PDB-14-WORLD-BOSS-RPC`(합산딜 레이드), `PDB-3-GAME-STATE-SCHEMA-V2`

## 1. 개요

카드가챠 시즌2에 **길드(크루)** 시스템을 추가한다. 캄몬스타즈가 게임·스트리밍 크루라는 정체성을 게임 내 구조로 옮겨, 방송인을 중심으로 시청자가 결속하고 그 결속이 게임 성과로 이어지게 한다.

현재 게임은 개인 플레이 중심이며 소셜 요소가 랭킹뿐이다. 길드는 **장기 리텐션**과 **방송 연계 볼거리**를 동시에 노린다.

### 설계 근거 데이터 (2026-07-25 실측)

| 지표 | 값 | 설계 반영 |
|---|---|---|
| DAU | 615~689명 | 길드 정원·목표치 산정 기준 |
| 총 계정 | 1,978 | 잠재 가입 모수 |
| 등록 스트리머 | 22명 | 최대 길드 수 = 22 |
| 후원 브릿지 실활성 스트리머 | 8명 | **초기 길드 수 부족 리스크의 근거** |
| 스트리머별 후원 참여자 | 13~34명 | 길드 기본 정원 30명 근거 |
| 월드보스 참여 | 회당 123~208명 | 레이드 참여율 추정 기준 |
| 활성 유저 포인트 중앙값 | 410,205P | 보상·비용 규모 기준 |

**핵심 함의**: DAU 650 ÷ 스트리머 22명 ≈ 30명. 길드 기본 정원 30명이 데이터와 정확히 맞는다. 다만 실활성 스트리머가 8명뿐이라 **인원 편중**이 최대 밸런스 리스크다(4절 참조).

## 2. 길드 구조

### 2.1 생성과 가입

- **생성 권한**: `gacha_s2_accounts.is_streamer = true` 계정만 가능. 스트리머 1인당 1길드.
- **가입**: 누구나 신청 가능 → **길드장(스트리머) 또는 부길드장 승인 필요**.
- **소속**: 1인 1길드. 무소속 상태도 정상 플레이에 아무 제약 없다(6.3 참조).
- **신청 제한**: 동시 신청은 최대 3개 길드까지. 승인되면 나머지 신청은 자동 취소.

### 2.2 역할

| 역할 | 권한 | 인원 |
|---|---|---|
| 길드장 | 전권(승인·추방·위임·해산·공지) | 1 (스트리머 고정, 이양 불가) |
| 부길드장 | 가입 승인·거절, 공지 수정 | 최대 2 |
| 길드원 | 컨텐츠 참여, 공헌 | 정원까지 |

길드장은 스트리머 계정에 고정한다. 스트리머가 방송을 쉬어도 길드가 유지되도록 **승인 권한은 부길드장에게 위임** 가능하게 한다(승인 병목 완화, 8절 리스크).

### 2.3 정원

기본 30명, 길드 레벨로 확장한다.

| 길드 레벨 | 정원 |
|---|---|
| 1~4 | 30 |
| 5~9 | 40 |
| 10+ | 50 |

상한 50명은 인기 스트리머 쏠림을 물리적으로 제한하는 장치다.

### 2.4 탈퇴·추방

- 자진 탈퇴 가능. 단 **탈퇴·추방 후 24시간 재가입 불가**.
- 주간 대항전 진행 중 탈퇴해도 **이미 적립된 개인 공헌은 이전 길드에 잔류**(점수 세탁 방지).

## 3. 4대 컨텐츠

### 3.1 길드 레벨 & 버프 — 성장 축

길드원의 일상 플레이가 **길드 공헌도(GP)** 로 쌓이고, 누적 GP로 길드 레벨이 오른다. 레벨 버프는 **길드원 전원에게 상시 적용**되어 소속의 실익을 만든다.

**공헌도 획득** (일일 개인 상한 있음 — 3.2와 동일 취지)

| 행동 | GP |
|---|---|
| 모험 스테이지 클리어 | 1 |
| 미니게임 1판 완료 | 2 |
| 월드보스 공격 1회 | 10 |
| 길드 레이드 공격 1회 | 15 |
| SOOP 후원 이벤트 발생(해당 스트리머 길드) | 20 |

**레벨 버프** (누적, 전원 적용)

| 레벨 | 필요 누적 GP | 버프 |
|---|---|---|
| 1 | 0 | — |
| 2 | 3,000 | 카드 EXP +3% |
| 3 | 8,000 | 포인트 획득 +3% |
| 5 | 25,000 | 카드 EXP +5%, 정원 40 |
| 7 | 50,000 | 에너지 회복 6분 → 5분 30초 |
| 10 | 120,000 | 포인트 획득 +7%, 정원 50 |

> 버프 수치는 의도적으로 작다. 길드는 **가산 보너스**여야 하며 무소속 유저를 무력화해서는 안 된다(6.3).

### 3.2 길드 공동목표 — 주간 미션, 라이트 유저 포용

매주 월요일 00:00 KST 리셋. 길드 전체가 함께 채우는 누적 목표.

**목표 예시** (인원 비례 스케일, 4.3 참조)

- 길드 누적 모험 클리어 `300 × 인원계수`회
- 길드 누적 미니게임 `200 × 인원계수`판
- 길드 누적 월드보스 공격 `120 × 인원계수`회

**개인 기여 상한**: 1인당 각 목표의 최대 8%까지만 집계. 소수 고인물이 혼자 끝내는 것을 막고 **라이트 유저의 기여 여지**를 남긴다. 이 게임의 미니게임 일일 포인트 상한(게임당 10,000P) 설계 철학과 같은 방향이다.

**보상**: 달성 시 길드원 전원에게 포인트 + 지원 아이템. 기여자만이 아니라 **전원 지급**(소속감 강화, 무임승차는 개인 기여 상한과 대항전 상위 집계로 견제).

### 3.3 길드 레이드 — 협력 보스

**기존 월드보스 로직을 그대로 재사용한다**(합산딜 vs 공동 HP, 개인 시도 횟수 제한, 결과 창 보상). 서버 자동딜은 월드보스와 마찬가지로 **없다**(2026-07-25 폐지 반영).

| 항목 | 값 |
|---|---|
| 일정 | 주 2회(수·토) 21:00 KST, 30분 |
| 참여 | 해당 길드원만 |
| 개인 시도 | 3회 (월드보스와 동일) |
| 처치 판정 | 길드원 합산딜 ≥ 레이드 HP |
| HP | **인원 비례**(4.2) |
| 보상 | 개인 포인트 + 길드 GP + 지원 아이템, 실패 시 감액 보상 |

월드보스와 시간대가 겹치지 않도록 21:00으로 배치한다(월드보스는 17~20시).

### 3.4 길드 대항전 — 길드 vs 길드

주간 리그. 월요일 00:00 KST 시작, 일요일 24:00 종료 후 정산.

**점수 산식**

```
길드 주간 점수 = Σ(길드원 개인 주간 공헌 점수 상위 20명)
```

**상위 20명만 집계**하는 것이 인원 불균형 보정의 핵심이다(4.1). 50명 길드가 30명 길드를 인원수만으로 이기지 못한다.

**티어 승강제**: 브론즈 → 실버 → 골드 → 다이아 → 챌린저. 각 티어 내 순위로 승격/강등.

**보상**: 순위별 포인트 + 길드 GP + 시즌 칭호(프로필 표시). 칭호는 방송에서 보여줄 수 있는 명예 보상이라 크루 대항 성격에 잘 맞는다.

## 4. 인원 불균형 보정 — 최우선 밸런스 과제

실활성 스트리머가 8명뿐이고 후원 참여자도 13~34명으로 편차가 크다. **인원수가 곧 승리가 되면 대항전이 무의미해진다.** 세 컨텐츠 모두에 보정을 건다.

### 4.1 대항전: 상위 N명 집계
상위 20명만 합산. 20명 미만 길드는 실제 인원만 합산하되, **인원 15명 미만 길드는 부족분을 평균값으로 보정**해 소규모 길드가 구조적으로 불리하지 않게 한다.

### 4.2 레이드: HP 인원 비례
```
레이드 HP = 기본HP × (참여인원 / 기준인원 20)
```
참여 인원이 확정되는 **레이드 시작 시점에 HP를 고정**한다(중도 가입으로 HP가 흔들리지 않게).

### 4.3 공동목표: 목표치 인원 비례
```
인원계수 = 길드원 수 / 30
```

## 5. 경제 설계

활성 유저 포인트 중앙값이 410,205P다. 길드 보상이 기존 경제를 흔들지 않도록 **월드보스 1회 보상(1,000~30,000P)과 같은 급**으로 맞춘다.

| 항목 | 규모 |
|---|---|
| 길드 생성 비용 | 무료 (스트리머 특권) |
| 가입 비용 | 무료 |
| 주간 공동목표 보상 | 전원 15,000~25,000P |
| 레이드 보상 | 성공 10,000~20,000P / 실패 3,000~6,000P |
| 대항전 보상 | 1위 30,000P ~ 참가 3,000P |
| 주간 총합(개인 기대치) | 약 40,000~70,000P |

주간 40,000~70,000P는 월드보스 주간 획득량(회당 최대 30,000 × 다수 회차)보다 작게 잡아, 길드가 **주력이 아닌 보조 수입**이 되게 한다.

**포인트 소각 장치**: 길드 레벨업은 활동 기반(GP)이지만, 별도로 **포인트 기부**로 GP를 소량 보충할 수 있게 해 인플레 완화 밸브를 둔다(기부 일일 상한 필요).

## 6. 설계 원칙

### 6.1 서버 권위 유지
모든 길드 명령은 기존 `PDB-11` 규약을 그대로 따른다 — **멱등키 + expectedRevision + 감사 로그**. 클라이언트 판정은 없다.

### 6.2 기존 로직 재사용
레이드는 월드보스 RPC 구조(공동 HP·개인 시도·결과 창)를 복제해 신규 위험을 줄인다.

### 6.3 무소속 유저 보호
길드는 **가산 보너스**다. 무소속 유저도 모험·월드보스·미니게임·랭킹 전부 정상 이용 가능하다. 길드 버프는 최대 +7% 수준으로 억제한다.

### 6.4 방송 친화
대항전 순위표와 레이드 진행도는 **방송에 띄우기 좋은 화면**으로 설계한다(큰 숫자, 실시간 갱신, 크루 로고).

## 9. 구현 로드맵

각 단계는 독립 배포 가능하다. **M1만으로도 소셜 가치가 발생**하므로 조기 배포 후 반응을 보고 다음 단계를 조정한다.

| 단계 | 범위 | 비고 |
|---|---|---|
| **M1** | 길드 생성·신청·승인·탈퇴·추방, 길드 목록/상세 UI | 소셜 뼈대. 컨텐츠 없이도 배포 가능 |
| **M2** | 공헌도(GP) 적립, 길드 레벨·버프 | 기존 명령에 GP 적립 훅 추가 |
| **M3** | 주간 공동목표 | 주간 리셋 배치 필요 |
| **M4** | 길드 레이드 | 월드보스 RPC 복제 |
| **M5** | 길드 대항전 리그 | 주간 정산 배치, 티어 승강 |
